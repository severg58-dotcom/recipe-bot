# Деплой на Render (бесплатно, без карты)

Бот работает на хостинге: ему не нужны VPN и прокси, а вам — открытая консоль.
Telegram не теряет сообщения при рестартах — обновления подхватываются из очереди.

## Шаг 0 — подготовка (уже сделано мной)

- Сервер здоровья на `$PORT` (Render требует открытый порт)
- `.gitignore` — токен и база в репозиторий не попадут
- Поведение: на хостинге `PROXY_URL` пуст → бот работает напрямую, охота за
  прокси не запускается

## Шаг 1 — GitHub (ваш аккаунт)

1. Зарегистрируйтесь: https://github.com/signup
2. Создайте репозиторий: кнопка **New repository** → имя `recipe-bot`,
   Public/Private — на ваш вкус, **без** галочек (пустой репозиторий)
3. Дальше — либо скажите мне «push» (я запушу, если git уже авторизован),
   либо выполните сами команды, которые я напечатаю:

```bash
cd C:\Users\Сергей\Projects\recipe-bot
git remote add origin https://github.com/<ВАШ_ЛОГИН>/recipe-bot.git
git push -u origin master
```

## Шаг 2 — Render (ваш аккаунт)

1. Регистрация: https://dashboard.render.com/register (проще всего — через GitHub)
2. **New → Web Service** → подключите репозиторий `recipe-bot`
3. Настройки сервиса:
   - **Name**: recipe-bot (или любое)
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type / Plan**: **Free** (обязательно!)
4. В разделе **Environment** добавьте одну переменную:
   - `BOT_TOKEN` = ваш токен из `.env` (тот, что в Telegram)
   - `PROXY_URL` — НЕ добавлять (на хостинге не нужен)
5. **Create Web Service** → дождитесь статуса **Live**
   (запишите адрес вида `https://recipe-bot-xxxx.onrender.com`)

## Шаг 3 — UptimeRobot (чтобы сервис не засыпал)

Бесплатный сервис спит без входящих HTTP 15 минут — а спящий бот не опрашивает
Telegram. Пингер решает это раз и навсегда:

1. Регистрация: https://uptimerobot.com
2. **Add New Monitor** → Type: **HTTP(s)** → URL: ваш адрес `https://...onrender.com`
   → Interval: **5 minutes**
3. Сохранить. Теперь сервис не спит никогда (и 750 бесплатных часов Render
   хватает: 31×24=744 < 750)

## Шаг 4 — проверка

Откройте бота в Telegram → `/start` → «🔎 Поиск рецептов» → «Картофель».
Работает — задание сдано 🎉

## Ограничения бесплатного хостинга

- Файл `favorites.db` стирается при каждом редеплое (избранное начнётся с нуля) —
  для учебного задания нормально, продвинутый вариант — бесплатный Postgres
  (но он удаляется через 30 дней) или платный диск
- Render может перезапустить сервис — сообщения при этом не теряются
- Деньги Render не спрашивает: карта не нужна
