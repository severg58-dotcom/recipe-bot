# Recipe Bot — структура Telegram-бота рецептов

Бот ищет рецепты через API и сохраняет их в избранное по кнопке.
Сейчас — только каркас: кнопки и заглушки, логика API/БД не подключена.

## Схема работы

```
/start
   └─ Главное меню (reply-клавиатура)
        ├─ 🔎 Поиск рецептов
        │     └─ пользователь вводит название блюда
        │           └─ карточка рецепта + inline-кнопки:
        │                ⭐️ Сохранить  → рецепт в избранное (БД)
        │                ➡️ Другой рецепт
        └─ ⭐️ Мои рецепты
              └─ список из БД в виде кнопок (название = кнопка)
                    └─ нажатие → полный рецепт: фото + текст
```

## Файлы

| Путь | Назначение |
|---|---|
| `bot.py` | Точка входа: Bot + Dispatcher, подключение роутеров |
| `config.py` | Токен и параметры API из `.env` |
| `keyboards/main_menu.py` | Reply-клавиатура: «Поиск рецептов» / «Мои рецепты» |
| `keyboards/recipe_kb.py` | Inline-кнопки карточки: «Сохранить», «Другой рецепт» |
| `keyboards/favorites_kb.py` | Кнопчатый список избранных рецептов |
| `handlers/start.py` | Команда /start и главное меню |
| `handlers/search.py` | FSM: запрос названия блюда → карточка рецепта с фото |
| `handlers/recipe_actions.py` | Callback-кнопки карточки: сохранить / другой рецепт |
| `handlers/favorites.py` | «Мои рецепты»: кнопки избранного → полный рецепт |
| `services/recipes_api.py` | Клиент TheMealDB: поиск, случайный, по id |
| `services/database.py` | SQLite (`favorites.db`): избранные рецепты |

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env   # и вставить токен от BotFather
python bot.py
```
